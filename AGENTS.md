# Правила проекта

## Стек

- Сервер: Python, FastAPI, асинхронные обработчики.
- Клиент: обычные HTML, CSS и JavaScript без frontend-фреймворка.
- Хранилище: JSON-файл с поездками.
- Тесты: pytest.

## Рабочий процесс

- Выполнять работу небольшими этапами и не переходить к следующему этапу без проверки текущего.
- Перед изменением прочитать файлы, которые будут изменены, и связанные с ними файлы.
- После каждого этапа запускать подходящие тесты или проверку запуска приложения.
- Каждое изменение оформлять отдельным понятным commit.
- После проверки отправлять commit в удалённый репозиторий.
- Не менять файлы, не связанные с текущей задачей.
- Не добавлять зависимости без необходимости.
- Не коммитить секреты, локальные настройки и файлы окружения.

## Требования к реализации

- Валидировать входные данные на границе API.
- Повторная отправка поездки с тем же `id` не должна создавать дубль.
- Расчёты сводки держать детерминированными и покрывать тестами.
- Сохранять существующий стиль проекта и делать минимальные изменения.
- Ошибки API возвращать с понятным сообщением и корректным HTTP-статусом.

## Проверка перед завершением этапа

- Запустить тесты.
- Проверить `git diff` и `git status`.
- Убедиться, что в изменениях нет секретов и несвязанных файлов.
